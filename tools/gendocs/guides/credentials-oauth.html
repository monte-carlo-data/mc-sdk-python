An OAuth client is a client id, its secret, and the Monte Carlo instance it belongs to, such as us1. The SDK exchanges them for an access token and renews it before it expires.

Create the client

  1. Open the API settings page in Monte Carlo and click Add.
  2. Choose an OAuth client. A personal client acts as you; a service client belongs to the account and has its own authorization groups.
  3. Copy the client id and the client secret. The secret is shown only once.

The instance is the Monte Carlo deployment your account runs on, such as us1 or eu1; the scope the dialog shows names it. API Authentication in the Monte Carlo docs has the details, including the permission each type of client needs.

Pass them in code

import pycarlo2

client = pycarlo2.new_client(
    pycarlo2.Options(client_id="<id>", client_secret=secret, instance="us1")
)

Read secret from wherever your application keeps secrets; don't commit it. Credentials passed this way win over the environment and the profile.

From the environment

In a script or CI, set these environment variables and pass no options:

MCD_DEFAULT_OAUTH_CLIENT_ID=<id>
MCD_DEFAULT_OAUTH_CLIENT_SECRET=<secret>
MCD_DEFAULT_INSTANCE_ID=us1
client = pycarlo2.new_client()

From the CLI's profile

If you set up the montecarlo CLI with montecarlo configure, the SDK reads the same profile from ~/.mcd/profiles.ini, so pycarlo2.new_client() needs no options either. To use a profile other than default, name it:

client = pycarlo2.new_client(pycarlo2.Options(profile="staging"))

or set MCD_DEFAULT_PROFILE=staging.

Check

print(pycarlo2.UsersApi(client).get_current_user())

It shows the user and account the credentials belong to.
