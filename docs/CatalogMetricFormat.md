# CatalogMetricFormat

How a metric's value is shown, from dbt's `config.meta.format`. A value added in dbt before it is added here is listed without a format.

## Enum

* `PERCENT` (value: `'percent'`)

* `CREDITS` (value: `'credits'`)

* `HOURS` (value: `'hours'`)
