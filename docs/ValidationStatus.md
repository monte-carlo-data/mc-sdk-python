# ValidationStatus

Whether one validation ran.  `completed`, `failed` and `timed_out` each carry a verdict, in `passed`. `pending`, `running` and `skipped` do not.

## Enum

* `PENDING` (value: `'pending'`)

* `RUNNING` (value: `'running'`)

* `COMPLETED` (value: `'completed'`)

* `FAILED` (value: `'failed'`)

* `TIMED_OUT` (value: `'timed_out'`)

* `SKIPPED` (value: `'skipped'`)
