# CredentialType

The kind of credential a generic collection agent presents to Monte Carlo.  `TOKEN` is a key id and secret the agent sends as headers. `OAUTH_CLIENT` is an OAuth 2.0 client the agent exchanges for short-lived access tokens.

## Enum

* `TOKEN` (value: `'TOKEN'`)

* `OAUTH_CLIENT` (value: `'OAUTH_CLIENT'`)
