An API token is a token id and its secret. The SDK sends the two together on every request.

Create the token

  1. Open the API settings page in Monte Carlo and click Add.
  2. Choose the type of key, personal or account-level, and when it expires. An account-level key needs a role that allows it; Account Owners have one.
  3. Copy the key id and the secret. The secret is shown only once.

API Authentication in the Monte Carlo docs has the details.

Pass them in code

import pycarlo2

client = pycarlo2.new_client(pycarlo2.Options(token_id="<id>", token_secret=secret))

Read secret from wherever your application keeps secrets; don't commit it. Credentials passed this way win over the environment and the profile.

From the environment

In a script or CI, set these environment variables and pass no options:

MCD_DEFAULT_API_ID=<id>
MCD_DEFAULT_API_TOKEN=<secret>
client = pycarlo2.new_client()

From the CLI's profile

If you set up the montecarlo CLI with montecarlo configure, the SDK reads the same profile from ~/.mcd/profiles.ini, so pycarlo2.new_client() needs no options either. To use a profile other than default, name it:

client = pycarlo2.new_client(pycarlo2.Options(profile="staging"))

or set MCD_DEFAULT_PROFILE=staging.

Check

print(pycarlo2.UsersApi(client).get_current_user())

It shows the user and account the credentials belong to.
